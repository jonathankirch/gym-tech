# 🏋️‍♂️ GymTech - Sistema de Gerenciamento

Sistema desenvolvido em **Java (Java Swing)** com persistência em banco de dados **PostgreSQL**, criado como trabalho acadêmico.

---

## 📂 Estrutura do Projeto

Para facilitar a execução e correção, note os seguintes arquivos e pastas na raiz do repositório:

- **`db.properties`**: Arquivo de configuração de conexão. Nele você deve definir o seu usuário, senha e porta do PostgreSQL local.
- **`postgresql/`**: Pasta que abriga o arquivo de backup (`gymtech.backup`) do banco de dados do sistema, restaure ele na sua máquina.

---

## 🛠️ Como Rodar o Projeto

### 1. Pré-requisitos

Certifique-se de ter instalado em sua máquina:

- **Java JDK** (versão 8 ou superior)
- **PostgreSQL**
- **Apache NetBeans** (Fortemente recomendado para rodar o projeto)

Adicione o repositório clonado no netbeans, e execute por lá...
